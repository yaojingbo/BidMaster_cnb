# Bid Master Web — 快速开始

> 打开浏览器，10 分钟体验「注册 → 配 AI → 选功能」全流程，三大基础功能马上上手。

> 想先看效果？打开 [演示中心](http://bidmaster.asia/) — 注册即用、不消耗你的 AI 配额，配好模型即可体验。

## 1. 注册 / 登录

进入 <http://bidmaster.asia/>，右上角点击「注册」或「登录」，用邮箱 + 验证码即可创建账号。

- 注册流程：邮箱 + 验证码 + 密码，30 秒搞定。
- 登录方式：邮箱 + 密码；忘记密码可走邮箱找回。
- 第一次进入会自动跳转到工作台，引导你完成下一步。

## 2. 配置你的 AI 模型

进入「设置 → AI 模型」，选择你常用的 AI 供应商并填入密钥，测试通过后即可使用。

- 系统支持多家主流 AI 供应商，你可以在设置页面里挑选最适合自己的那一个。
- 至少配 1 个供应商后，才能使用要素提取和开标分析功能。
- 切换供应商不需要重启页面，配置即时生效。

## 3. 选择你要的功能

进入工作台，根据需要选择以下三大基础功能之一。

### 3.1 要素提取

- **单文件要素提取**：上传一份招标文件，自动识别关键要素并生成结构化卡片，方便阅读与引用。
- **多文件批量要素提取**：上传多份类似招标文件，横向对比同一要素在不同项目中的差异，输出对比表。

### 3.2 开标分析

- 根据你提供的开标结果文件，分析开标情况。
- 在分析页勾选你关心的分析维度，系统会自动计算并生成 AI 综合分析报告。

### 3.3 模拟编制

- 针对某一类项目招标文件进行整合分析，按四步引导式流程，最终生成一份自定义的项目招标文件。
- 新生成的文件可以继续走要素提取做校验，反复迭代直到满意。
