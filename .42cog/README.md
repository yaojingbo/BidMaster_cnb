# .42cog/ - 认知敏捷法文档

本目录采用 RCSW 工作流：Intent → Real → Cog → Spec → Work。

> **分工线**：`.42cog/` 装**陈述**（这个系统是什么样）；`specs/`（根级）装**标准**（产出该长什么样）；
> `CLAUDE.md` 装**规矩**（你该怎么干）。三者不串门。

## 文件与子目录

- `intent.md` - **意向书**：收敛方向、真难题、不做什么。唯一必须人过目的一份
- `meta/` - 项目元数据（名称、定位、价值、技术栈、里程碑、交接、依赖）
- `real/` - 现实约束（底线红线、日程、资源、使用者）
- `cog/` - 认知模型（实体关系、参与者、关键关系）
- `work/` - 工作记录（任务分解、进度追踪）
- `others/` - 其他文档

> 规约（产出标准）已迁至根级 `specs/`，不再放在本目录。

## 工作流

1. **Intent** - 定收敛方向（`.42cog/intent.md`）
2. **Real** - 分析现实约束
3. **Cog** - 建立认知模型
4. **Spec** - 输出规约（`specs/`）
5. **Work** - 执行开发
