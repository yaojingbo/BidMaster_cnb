## 二、PDF 下载报错修复与自动化验证

### 问题
用户在文件管理中点击 PDF 下载按钮报错，并提供日志：

```text
/Users/yaojingboV2/Downloads/bid-master-logs_2026-07-09.txt
```

日志核心错误：

```text
counter(page).display() can only be used when context is known
```

### 根因
Typst 页脚中直接使用 `counter(page).display()`，但该表达式需要在 `context` 中执行，否则编译失败，导致后端返回 500。

### 修复
将页脚页码修复为 Typst 支持的上下文写法：

```typst
footer: context align(center, text(...)[#counter(page).display()])
```

### 自动化验证
已覆盖：

- 后端 Typst PDF 生成：
  - 要素提取 PDF：通过
  - 模拟编制 PDF：通过
  - 开标分析 PDF：通过
  - 即时 Markdown PDF：通过
- 文件管理页 PDF 按钮自动化点击：
  - “要素提取”页签 PDF 下载：通过
  - “模拟编制”页签 PDF 下载：通过
  - “开标分析”页签 PDF 下载：通过
- 生成 PDF 文件检查：
  - 文件头均为 `%PDF`
  - PDF 内容可正常读取
  - 排版检查未发现编译级错误
